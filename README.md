OVERVIEW:

This health app is a work-in-progress tool designed to log, track, and analyze physical wellness data. It allows users to enter health-related information, monitor their progress toward personal goals, and view their development over both short and long periods.



HOW IT WORKS:

After logging into the program users can enter their data, which is processed through our Inter-Process Communication (IPCP) system. The application then communicates with its local data storage to save or retrieve information as needed.The data is processed and analyzed to evaluate user progress and goals. The results are then presented through the application's data display features, using graphs and numerical summaries to help users understand their progress over time.


PROJECT STATUS:

This project is currently under development; features and functionality will continue to evolve as the team builds and integrates the different components of the application.


TOOLS:

This project uses C++, Java, and Json. As we continue to develop this list may expand


ARCHITECTURE: USER <-> UI <-> IPCP/Communication <-> Data Processing <-> Local Data Storage
